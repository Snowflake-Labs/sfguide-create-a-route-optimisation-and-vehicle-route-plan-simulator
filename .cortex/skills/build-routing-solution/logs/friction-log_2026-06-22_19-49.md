## Friction points + resolutions
1. **React 19 `useRef` typing** — `useRef<T>(null)` now returns `RefObject<T|null>`; the ported
   `useFitMap` declared `RefObject<HTMLDivElement>`. Fix: widen interface to `| null`.
   *Prevent:* note in porting guide — widen ported ref-return interfaces for React 19.
2. **`experimental.instrumentationHook` removed in Next 15.5** — build failed on the config key.
   Fix: drop it (instrumentation.ts is default-on). *Prevent:* scaffold without the flag.
3. **api/index.ts barrel** re-exported not-yet-ported modules (regions/studio/fleet) → build
   failure. Fix: trim barrel, re-add each export as its page lands. *Prevent:* port barrel last.
4. **`.js` ESM import extensions** in the ported server modules don't resolve under Next webpack.
   Fix: `sed` strip `.js` on relative imports at copy time. *Prevent:* documented in memory.
5. **callProcedure double-qualifies** fully-qualified procs (prepends SF_DATABASE.CORE). The
   observability ingest proc is `OBSERVABILITY.INGEST_ORS_METRICS`. Fix: use `runSql` with the
   full CALL directly. *Prevent:* only pass CORE-relative names to callProcedure.
6. **Persistent zsh lost PATH mid-session** (git/head "command not found") and choked on inline
   `#` comments in one-liners. Fix: prefix bash with `export PATH=...`; avoid inline `#`.
   *Prevent:* documented in r5 memory.
7. **Matrix viewer route paths** were flat (`/api/matrix/viewer-inventory`), not `/api/matrix/viewer/*`
   as an early inventory paraphrased. Fix: read the real source before porting. *Prevent:* always
   confirm exact `router.get(...)` paths from source, not summaries.

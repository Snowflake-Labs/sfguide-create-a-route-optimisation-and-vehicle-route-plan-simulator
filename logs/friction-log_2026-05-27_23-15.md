## Root cause (confirmed)

`POST /api/fx/offer-route` returned 500 because `freight_exchange.ts` called `OPENROUTESERVICE_APP.CORE.DIRECTIONS` with wrong arg order `(ARRAY, profile, region)` as a scalar - Snowflake error `Unknown user-defined function`. Correct shape: `FROM TABLE(DIRECTIONS(profile, [pickup], [dropoff], region))`.

Console `UPDATE ROUTE_OPTIMIZATION.CONFIG` 403s were stale-bundle noise (removed from source in v1.1).

## Friction points

### F1 - ISOCHRONES multi-overload default literal `''time''` in 02_routing_functions.sql

- **Symptom:** `syntax error ... unexpected 'time'` when creating `ISOCHRONES(method, locations, ranges, ...)`.
- **Resolution:** Use `DEFAULT 'time'` in the module file (not doubled quotes).
- **Recommendation:** Skill note: defaults in `.sql` module files use single quotes; doubled quotes are only inside the nested `AS '...'` body strings.

### F2 - Multi ISOCHRONES 404 until gateway v1.1.4 deployed

- **Symptom:** New `_ISOCHRONES_RAW(..., options VARIANT, ...)` → `/isochrones` returned 404 from old gateway.
- **Resolution:** Built/pushed `routing_reverse_proxy:v1.1.4`, staged spec, SUSPEND/ALTER/RESUME `routing_gateway_service`. Probe then returned `GEO_LEN=1392`.

### F3 - External curl to control app returns 302 (SSO)

- **Symptom:** `curl` to `/api/fx/offer-route` gets redirect, not JSON.
- **Resolution:** Verified via Snowflake SQL (`DIRECTIONS` + new `ISOCHRONES`) and image deploy; UI verification requires browser session.
- **Recommendation:** Document smoke-test SQL probes in freight-exchange skill for agents without ingress cookies.

## Friction points + recommendations

### 1. Path typo on `write` — LARGE file lost-and-found
**What happened:** First `write` of BackloadMatching.tsx had a typo `/Users/obielov/Ments/...` instead of `/Users/obielov/Documents/...`. The tool silently created the typo directory and wrote the file there. Original BackloadMatching.tsx was untouched. Took a moment to detect, then `cp` + `rm -rf` to recover.

**Recommendation:** Always re-verify the absolute path before a `write` of a brand-new long file. Consider adding a sanity probe that the parent directory existed before the write.

### 2. `docker build --ignorefile` is podman-only
**What happened:** AGENTS.md instructs `docker build ... --ignorefile .dockerignore.prebuilt`. That flag only exists on podman/buildah. Docker CLI rejected it.

**Recommendation:** Update AGENTS.md to say "use `podman build` (NOT `docker build`) when passing `--ignorefile`" or change the strategy to: temporarily rename `.dockerignore` → `.dockerignore.bak`, copy `.dockerignore.prebuilt` → `.dockerignore`, run `docker build`, restore.

### 3. SPCS registry auth-token expiry mid-push
**What happened:** Standard `podman push` failed at the 4th blob with 401 / "invalid username/password". This is the well-documented SPCS bearer-token-expires-mid-PUT bug. Falling back to `crane push` worked first try.

**Recommendation:** AGENTS.md already documents this. We should consider making `crane push` the DEFAULT path in skill instructions and reserve podman/docker push as the fallback, since the `crane` flow is reliable and roughly the same wall time once you account for the inevitable retries.

### 4. Podman cache reuse looked alarming but was correct
**What happened:** Build output showed "Using cache" for STEP 8 (COPY dist) and the final image hash `afdbf2a55e91` matched a previous run. Worried initially that my source changes weren't included, until I verified the new bundle contents with `podman run sh -c "grep 'Allowed deviation' /app/dist/assets/*.js"`.

**Recommendation:** Add a one-liner verification step to AGENTS.md: after build, `podman run --rm <image> grep <unique-string-from-changes> /app/dist/assets/*.js` to confirm the change made it into the image before push.

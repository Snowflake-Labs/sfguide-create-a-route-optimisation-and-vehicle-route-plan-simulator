## Friction Points

### F1: Repo/branch image version far behind locally-built images

- **Step:** Build images / version bump
- **Severity:** Medium
- **What happened:** This branch (`feat/oleksii-bielov_snow-feat`) and the running service were at `ors_control_app:v1.1.98`; `origin/dev` is even older at `v1.1.90`. Yet the local Podman cache held images up to `v1.2.29` (built ~31 min earlier) on both `pm-fleet-test` and `pm-geolab` registries. The v1.2.x line is a separate parallel worktree/branch not reflected in this repo's tracked source (neither dev nor this branch). Bumping to `v1.1.99` risked confusion about which lineage is authoritative.
- **Resolution:** Verified before deploying: (a) `origin/dev` ORS_CONTROL_APP_TAG = v1.1.90; (b) this branch is 21 commits ahead of dev and carries the entire emergency-response feature (v1.1.93->v1.1.98); (c) `SYSTEM$GET_SERVICE_STATUS` confirmed the live service on wgb26798 was still v1.1.98 (unchanged), so v1.1.98 -> v1.1.99 is a correct forward step for this account. Proceeded with v1.1.99.
- **Recommendation:** The emergency-response branch is far ahead of `dev` and should be PR'd into `dev` to converge the version lineage. The v1.2.x images on shared registries suggest multiple uncoordinated version series; consider a single authoritative `image-versions.env` per account and a pre-deploy check that compares the intended tag against the live `SYSTEM$GET_SERVICE_STATUS` image to avoid accidental regressions across parallel sessions.

### F2: macOS lacks `timeout`; AGENTS.md push snippet double-nests repo path

- **Step:** Push image
- **Severity:** Low
- **What happened:** `timeout 240 podman push ...` failed (`command not found: timeout` on macOS zsh). Separately, the AGENTS.md build snippet tags `$REPO_URL/openrouteservice_app/core/image_repository/ors_control_app:...`, but `$REPO_URL` already ends in `/openrouteservice_app/core/image_repository`, so following it verbatim double-nests the path.
- **Resolution:** Dropped `timeout` and ran `podman push` directly (completed in ~2 min, no hang). Used `$REPO_URL/ors_control_app:v1.1.99` (matching the live image path).
- **Recommendation:** In AGENTS.md, use `$REPO_URL/ors_control_app:vX.Y.Z` (single nesting) and avoid `timeout` in macOS examples (or note `gtimeout` from coreutils).

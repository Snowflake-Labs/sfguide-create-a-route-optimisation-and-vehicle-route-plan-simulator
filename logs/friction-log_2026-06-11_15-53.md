## Friction Points

### F1: `podman push` failed mid-push with the SPCS token-refresh bug

- **Step:** Push image
- **Severity:** Medium
- **What happened:** After 8/9 blobs copied, `podman push` aborted with `Error: trying to reuse blob ... unable to retrieve auth token: invalid username/password: unauthorized: Authorization Failure`. This is the known SPCS registry bearer-token expiry-mid-PUT issue documented in AGENTS.md.
- **Resolution:** Followed the AGENTS.md crane workaround: `snow spcs image-registry login` (refresh), `podman save -o /tmp/img.tar`, `crane push /tmp/img.tar <image>`. Completed cleanly in ~3 min.
- **Recommendation:** Given this bug has now recurred across multiple deploys this session (it intermittently hit v1.1.99/100 and fully blocked v1.1.101), consider making `crane push` the DEFAULT documented push path for the control app rather than the fallback, to avoid a failed `podman/docker push` attempt each time.

## Friction points + resolutions

### F1: "Free" demographics Marketplace listings are tiny samples
- **Severity:** WARNING / DOCS_GAP
- No Fret Data "U.S. Census Demographics — Free" (GZ1M6ZYDCF2) installed as a
  24-row sample, not full coverage. **Resolution:** switched to SafeGraph Open
  Census (GZSNZ2UNN0) — genuinely free + full (242k CBGs). **Prevention:** the
  roadmap doc + this log now flag that demographics "Free Dataset" listings are
  usually teasers; SafeGraph Open Census is the real free full-coverage source.

### F2: `SAMPLE` is a Snowflake reserved word
- **Severity:** ERROR (caught in validation)
- A CTE named `sample` in the depot query failed to parse. **Resolution:** renamed
  to `bldg_sample`. Same class as the known `rows` reserved-word gotcha.

### F3: ST_CENTROID(ST_COLLECT(polygons)) returns a Polygon
- **Severity:** ERROR (caught in validation)
- `ST_Y` rejects the polygon-typed collection. **Resolution:** depot computed as
  `AVG(ST_Y/ST_X of per-building ST_CENTROID)`. Also: BUILDING.GEOMETRY is a
  polygon, so bbox checks must wrap it in ST_CENTROID.

### F4: SafeGraph ACS identifiers need quoting; FIPS in a different table
- **Severity:** ERROR (caught in validation)
- Table names are digit-leading (`2020_CBG_B01`) and ACS columns mixed-case
  (`B01001e1`) so both must be double-quoted. STATE/COUNTY FIPS live in
  `2020_CBG_GEOMETRY_WKT`, not the metadata table. **Resolution:** quoted all
  identifiers; sourced FIPS from the geometry table.

### F5: Overture health categories differ from intuition
- **Severity:** WARNING
- There is no bare `pharmacy`/`doctor`/`grocery_store` BASIC_CATEGORY; the real
  values are `pharmacy_and_drug_store`, `urgent_care_center`,
  `outpatient_care_facility`, etc. **Resolution:** discovered + used real values.

### F6: Deploy refused on unrelated untracked friction logs
- **Severity:** INFO / WORKAROUND
- deploy_fleet_admin_app.sh clean-tree guard tripped on friction logs from other
  parallel chats. **Resolution:** ALLOW_DIRTY=1 (my own changes were committed).

### F7: SEED_DATA_STAGE absent on this account

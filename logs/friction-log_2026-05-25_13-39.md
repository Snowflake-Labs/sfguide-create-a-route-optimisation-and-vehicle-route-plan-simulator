### 2. `docker --ignorefile` flag rejected
- `docker build --ignorefile .dockerignore.prebuilt ...` errors with `unknown flag: --ignorefile`. That flag is podman-specific.

- Recommendation: AGENTS.md "Control App Image Deployment" already calls out ARM Mac/podman, but the command snippet still says `docker build`. Add a "use podman if you need `--ignorefile`" sentence to avoid the false start.

- Resolution: `kill` the orphan PID before re-running.
- Recommendation: `crane push` failures should print a clearer message; consider documenting `lsof /tmp/<tar>` and `pgrep crane` checks before each push.
